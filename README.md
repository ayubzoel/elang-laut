Elang Laut (Sea Eagle) is an original flight game: a small prop plane over a procedurally generated tropical archipelago. Take off from runway 09, fly through five glowing rings over the islands, and land back on the runway before the fuel runs out. It plays offline in a desktop browser from its own static files, with keyboard and mouse — an arcade flight model with stalls, banked turns and landing checks, a full instrument panel (airspeed, altitude, heading tape, artificial horizon, fuel and damage gauges, minimap), synthesised WebAudio sound, and a seeded island world with a lighthouse, a fishing town and 380 palms. Three.js is vendored; there are no other dependencies and no network requests.

## Run it

```sh
cd game && python3 -m http.server 8080
# then open http://localhost:8080/
```
